# US-102 — Estruturar página de especialistas

## Objetivo

Disponibilizar uma página institucional para apresentar os seis especialistas da Clínica Bem-Estar.

## Critérios de aceite

- [x] Criar `pages/especialistas.html`.
- [x] Exibir seis especialistas.
- [x] Informar foto, nome, formação, especialidade, registro profissional e horário de atendimento.
- [x] Utilizar estrutura semântica com `header`, `nav`, `main`, `section`, `article`, `figure` e `figcaption`.
- [x] Adicionar texto alternativo às imagens.
- [x] Incluir navegação para as páginas previstas no projeto.
- [ ] Validar no W3C após os arquivos de imagem serem adicionados.

## Observações

Os dados dos perfis e os caminhos das imagens são conteúdo inicial de demonstração e devem ser confirmados pela equipe antes da publicação em produção.

A estilização visual e a adaptação para dispositivos móveis serão tratadas nas User Stories das Sprints seguintes.

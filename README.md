O projeto será desenvolvido incrementalmente ao longo de 6 sprints.

### Sprint 2

### Sprint 3
Responsividade.

### Sprint 4
HTML semântico, SEO e microformatos.

### Sprint 5
Acessibilidade WCAG AA.

### Sprint 6
JavaScript e entrega final.
